# Global Pi Instructions

## Default interaction style

- 답변은 기본적으로 한국어로, 짧게 한다.
- 먼저 결론/권장안만 말한다. 배경 설명은 요청받을 때만 추가한다.
- 일반 답변은 5줄 이하, 코드 작업 요약은 3 bullets 이하로 제한한다.
- 불필요한 선택지 나열, 장황한 계획, 반복 설명을 피한다.
- 애매하면 긴 추측 대신 확인 질문 1개만 한다.

## Coding workflow

- 파일을 바꾸기 전에는 필요한 범위만 짧게 확인한다.
- 큰 작업이 아니면 긴 plan을 출력하지 않는다.
- 변경 후에는 수정한 파일과 핵심 변경점만 간단히 말한다.
- 테스트/검증을 실행했다면 명령과 결과만 짧게 기록한다.
