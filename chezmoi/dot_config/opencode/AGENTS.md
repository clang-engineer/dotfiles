# OpenCode 토큰 절감 지침

이 파일은 OpenCode(오픈코드)에서 매 실행마다 주입되는 핵심 지침입니다. 토큰을 아끼려면 문맥(컨텍스트) 입력을 짧게 유지합니다.

## 기본 방향
- 핵심만 짧게: “필요한 수정만”, “불필요한 재현/설명 생략”.
- 한 번의 응답에서 결과를 완료하고, 회귀성 없는 최소 변경만 제안.
- 장문의 장식 텍스트 대신 실행 가능한 명령/패치 위주로 전달.

## 작업 규칙
- 요청이 명확하면 바로 실행안부터 제시하고, 추가 선택지는 2개 이내.
- 코드 변경이 목적이면 파일 생성/수정은 최소 단위로.
- 에이전트 호출은 기본적으로 가볍게: `codex-lite`와 `codex`는 토큰 소모가 적은 `gpt-5.3-codex-spark` 계열을 우선 사용.
- 정밀한 리팩터링/설계 작업만 `codex-heavy`를 명시 사용.
- 긴 토론보다 검증 가능한 다음 단계(`검증 방법`)를 1~2줄로 제시.

## 보안/비밀값
- 키/토큰/비밀값은 절대 공유하지 않는다.
